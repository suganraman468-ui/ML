# ML Assignment 2 — Classification Models + Streamlit Deployment

## a. Problem Statement
Breast cancer diagnosis is traditionally based on manual examination of cell
nuclei from a biopsy image, which is time-consuming and subject to human
error. This project builds and compares multiple supervised classification
models that predict whether a breast tumor is **malignant** or **benign**
based on numeric features computed from digitized images of a fine needle
aspirate (FNA) of a breast mass. The goal is to identify which algorithm
generalizes best on this dataset and to expose the models through an
interactive Streamlit app for evaluation.

## b. Dataset Description
- **Name:** Breast Cancer Wisconsin (Diagnostic) Dataset
- **Source:** UCI Machine Learning Repository (also bundled in
  `sklearn.datasets.load_breast_cancer`)
- **Instances:** 569
- **Features:** 30 numeric features (mean, standard error, and "worst" value
  of 10 real-valued measurements per cell nucleus — e.g. radius, texture,
  perimeter, area, smoothness, concavity, symmetry)
- **Target:** Binary — `0 = Malignant`, `1 = Benign`
- **Class balance:** 212 malignant / 357 benign
